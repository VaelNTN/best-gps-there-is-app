# Best GPS There Is

Multilingual Android & Web GPS navigation app built with TypeScript, Vite, Capacitor 8, and MapLibre GL JS.

## 4 Transport Modes
1. **Walk (`pedestrian`)** — walking paths, parks, stairs avoidance, walking speed tuning
2. **Bicycle (`bicycle`)** — bike lanes, road/city/hybrid/MTB types, hill avoidance
3. **Car (`auto`)** — fastest/shortest routes, toll/highway/ferry options
4. **Heavy / Truck (`truck`)** — custom height, width, length, total weight, axle load, ADR hazmat, and presets (Van 3.5t, Box 12t, Semi 40t, Mega LZV 60t, Camper)

## 7 Supported Languages
Nederlands (`nl`), English (`en`), Deutsch (`de`), Français (`fr`), Español (`es`), Polski (`pl`), Türkçe (`tr`).

## Optional Commercial Routing Keys
Works out of the box via OpenFreeMap vector tiles + Komoot Photon/Nominatim + FOSSGIS Valhalla (plus OSRM fallback). In **Settings**, you can also enter an optional OpenRouteService or HERE Routing API v8 key for commercial >150km HGV routing.
